# CYBER HUNTERS — دليل الإعداد والنشر (نسخة أولية)

هذه حزمة أولية لواجهة لعبة ويب. **لن تعمل المنافسة بين أجهزة الطلاب قبل إعداد Supabase وإنشاء جلسة تدريبية.**

## محتويات الحزمة
- `index.html` واجهة اللعبة.
- `styles.css` التصميم المتجاوب.
- `app.js` منطق المهمات والنتائج.
- `config.js` مكان إعداد بيانات Supabase العامة.
- `supabase_schema.sql` جداول قاعدة البيانات وسياسات الوصول.

## 1) إنشاء مشروع Supabase
1. افتحي https://supabase.com وسجلي الدخول.
2. أنشئي مشروعاً جديداً باسم `cyber-hunters`.
3. احتفظي بكلمة مرور قاعدة البيانات في مكان آمن ولا تشاركيها.
4. من لوحة المشروع افتحي SQL Editor.
5. افتحي ملف `supabase_schema.sql` وانسخي محتواه إلى SQL Editor ثم اضغطي Run.
6. من Project Settings ثم API انسخي Project URL و anon/public key.

## 2) إعداد config.js
افتحي `config.js` واستبدلي:
- `PASTE_YOUR_SUPABASE_PROJECT_URL_HERE` برابط Project URL.
- `PASTE_YOUR_SUPABASE_ANON_KEY_HERE` بمفتاح anon/public فقط.

لا تضعي `service_role` أو كلمة مرور قاعدة البيانات في ملفات الموقع.

## 3) إنشاء جلسة تجريبية
من Supabase افتحي Table Editor ثم جدول `sessions` ثم Insert row:
- `code`: CYBER26
- `title`: CYBER HUNTERS Training
- `status`: active

اتركي `id` و `created_at` للقيم الافتراضية.
بعدها يستطيع الطلاب تجربة الانضمام باستخدام الرمز `CYBER26`.

## 4) رفع الملفات إلى GitHub
1. افتحي مستودعك: https://github.com/dianatahrawi-stack/cyber-hunters
2. اضغطي Add file ثم Upload files.
3. فكّي ضغط ملف ZIP على جهازك.
4. ارفعي الملفات الموجودة داخل مجلد `cyber-hunters` (وليس مجلد ZIP نفسه).
5. اضغطي Commit changes.

## 5) النشر عبر Netlify
1. افتحي https://app.netlify.com وسجلي الدخول.
2. اختاري Add new site ثم Import an existing project.
3. اختاري GitHub واسمحي بالوصول إلى المستودع `cyber-hunters`.
4. اختاري المستودع.
5. اتركي Build command فارغاً و Publish directory = `.` إن طلبت المنصة ذلك.
6. اضغطي Deploy.
7. سيظهر رابط ينتهي بـ `netlify.app`.

## تنبيه مهم قبل استخدامه مع طلاب حقيقيين
هذه نسخة MVP للتجربة التقنية، وليست نظام مسابقات آمناً للاستخدام العام بعد. سياسات التحديث الحالية تسمح بتعديل درجات اللاعبين دون مصادقة مناسبة، كما أن صلاحيات المدرب ولوحة النتائج المباشرة الكاملة غير مكتملة. لا تستخدميها لتقييم رسمي أو تجمعي أرقاماً جامعية أو بيانات شخصية حساسة قبل تقوية المصادقة وسياسات RLS وإضافة لوحة تحكم مدرب موثقة. استخدمي أسماء عرض فقط في التجربة الأولى.

## ما الذي لم يكتمل بعد؟
- دخول آمن للمدربة وصلاحيات إنشاء/إيقاف الجلسات.
- لوحة ترتيب مباشرة موثقة.
- حماية من تكرار الإجابات والتلاعب بالنقاط على مستوى الخادم.
- QR Code تلقائي وتقارير قابلة للتنزيل.
- مؤقت مركزي وتحكم المدربة بفتح المهمات.
